FF Live Draft Support

Need help with FF Live Draft? Email support@fflivedraft.app.

Purchases

Unlimited scans are a one-time in-app purchase. If you previously purchased the unlock, select Restore Purchases. Make sure the device is signed in with the Apple Account used for the original purchase.

Draft board scanning

For best results, use a clear, well-lit image with player names visible and minimal glare. Retake the photo if the scan does not recognize enough names.

Rankings

The app includes default rankings and supports importing a compatible rankings source URL.
